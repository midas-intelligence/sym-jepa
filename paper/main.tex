\begin{abstract}
We study whether latent world models can learn the transition dynamics of
symbolic rewrite systems purely from observation. We frame propositional
logic simplification as a Markov decision process where states are expression
trees, actions are rewrite rules, and transitions are deterministic. A
Transformer-based encoder maps expressions to a continuous latent space, and
a predictor conditioned on the rule identifier forecasts the next latent
state. The model is trained end-to-end on synthetically generated
before/after pairs and is never given the rule definitions. A learned value
function guides greedy action selection at inference. Across three seeds, the
model solves $33.0 \pm 0.2\%$ of test expressions to Conjunctive Normal
Form within 25 steps, exceeding a greedy heuristic that has access to
ground-truth outcomes ($31.3\%$). Analysis of the learned representations
reveals emergent semantic structure: logically equivalent expressions
cluster $5.8\times$ closer than distinct ones, a property that vanishes
without distributional regularization. Code is available at
\texttt{[redacted for review]}.
\end{abstract}

\section{Introduction}

A world model predicts the consequences of an action given the current state,
allowing an agent to evaluate candidates without executing them in the
environment. Joint-Embedding Predictive Architectures
(JEPA)~\cite{assran2023ijepa,lecun2022path} implement this idea by
predicting future \emph{representations} rather than reconstructing raw
observations, which focuses capacity on task-relevant features and avoids
modelling irrelevant detail. Recent work has shown that JEPA world models
can support zero-shot robotic manipulation~\cite{assran2025vjepa2} and
efficient latent planning from pixels~\cite{maes2026lewm}, but all
existing instantiations operate on visual or continuous-control domains.

Symbolic mathematics presents a structurally different challenge. States are
discrete trees, actions are combinatorial (each rule may apply at many
positions), and the transition function is deterministic yet
non-trivial---a single distribution step can double expression size. We
investigate whether a latent world model can learn these dynamics from
data alone, without access to the rule definitions, and whether the learned
representations support planning.

Concretely, we consider simplification of propositional logic expressions
toward Conjunctive Normal Form (CNF) under 15 standard rewrite rules.  The
model receives an expression tree encoded as a structured tensor and a rule
identifier (an integer); it predicts the latent state of the rewritten
expression. At no point is the model told what any rule does---it learns
the mapping from $280{,}286$ observed transitions.

We report three findings:
\begin{enumerate}
\item A learned value function that scores actions via predicted latent
states outperforms a greedy heuristic that has access to ground-truth
outcomes ($33.0\%$ vs.\ $31.3\%$ solve rate, $p{<}0.05$, three seeds).
\item The latent space captures logical equivalence as emergent structure:
truth-table-equivalent expressions are $5.8\times$ closer than
non-equivalent ones (Semantic Clustering Score $= 5.76 \pm 0.12$).
\item Distributional regularization (SIGReg) is necessary to prevent
representation collapse; without it, effective rank drops from $91\%$
to $16\%$ of the embedding dimension and semantic clustering vanishes.
\end{enumerate}

\section{Related Work}

\paragraph{Latent world models.}
I-JEPA~\cite{assran2023ijepa} introduced joint-embedding prediction for
images; V-JEPA~2~\cite{assran2025vjepa2} extended it to video and robotic
planning. LeWorldModel~\cite{maes2026lewm} demonstrated stable end-to-end
JEPA training from pixels with two loss terms
(prediction~$+$~SIGReg~\cite{balestriero2025lejepa}), achieving
$48\times$ faster planning than reconstruction-based alternatives. Discrete
World Models via Regularization~\cite{dwmr2026} learn Boolean latent states
for environments with combinatorial structure. All of these target visual or
physical domains; none address symbolic rewriting.

\paragraph{Neural symbolic rewriting.}
The Neural Rewriting System~\cite{petruzzellis2024nrs} and its successor
FastNRS~\cite{petruzzellis2025fastnrs} learn formula simplification via
modular sequence-to-sequence architectures, producing symbolic output in
token space. Our approach differs in that we predict in latent space and
never generate symbolic output; the model selects actions while a symbolic
engine executes rewrites. Piotrowski et~al.~\cite{piotrowski2019neural}
showed that Transformer-based models can learn symbolic rewriting with
$80$--$90\%$ accuracy on polynomial simplification.

\paragraph{Collapse prevention.}
LeJEPA~\cite{balestriero2025lejepa} introduced SIGReg, a regularizer that
enforces isotropic Gaussian embeddings via random projections and the
Epps--Pulley characteristic function test. It eliminates the need for
exponential moving average target encoders, stop-gradients, or asymmetric
architectures. The Critiques of World Models~\cite{xing2025critiques}
formalized the collapse vulnerability: latent prediction loss admits a
trivial minimum where the encoder maps all inputs to a constant
(Proposition~1). Our ablation empirically confirms this result in a symbolic
domain.

\section{Problem Formulation}

We define an MDP $(\mathcal{S}, \mathcal{A}, T, R)$ over propositional
logic:

\begin{itemize}
\item $\mathcal{S}$: expression trees over variables $\{p, q, r, s\}$ with
operators $\{\wedge, \vee, \neg, \rightarrow, \leftrightarrow, \top,
\bot\}$, bounded at depth~$6$ (at most $127$ nodes).
\item $\mathcal{A}$: $15$ deterministic rewrite rules toward CNF---implication
and biconditional elimination, De~Morgan's laws, distribution of $\vee$
over $\wedge$, double negation, complement, identity, annihilation, and
idempotency---each applied at a specific tree position.
\item $T$: deterministic; applying rule~$a$ at position~$p$ in state~$s$
yields a unique successor $s'$.
\item $R$: $\text{cnf\_distance}(s)$, the count of structural violations
of CNF form in the AST. Computable in $O(n)$; $R = 0$ when $s$ is in CNF.
\end{itemize}

Pattern matching is commutative for $\wedge$ and $\vee$: e.g.,
complement-$\wedge$ matches both $A \wedge \neg A$ and $\neg A \wedge A$.
The branching factor is $5$--$13$ actions per state, making exhaustive
search intractable beyond shallow depths.

\section{Method}

\subsection{Encoder}

An 8-layer Transformer encoder maps BFS-encoded expression trees to a
$384$-dimensional latent vector. Each of the $127$ BFS positions receives a
content embedding---the concatenation of a node-type embedding
($d/2$-dimensional, covering $8$ operator types plus padding) and a
variable-identity embedding ($d/2$-dimensional, covering $\{p,q,r,s\}$
plus padding)---summed with a tree-aware positional embedding that combines
a learned depth embedding ($8$ levels) with a learned BFS-index embedding.
All positions attend to all others via full self-attention; padding
positions are masked. Each layer uses pre-normalization and
LayerScale~\cite{touvron2021cait} (initialized at $10^{-4}$) with a GELU
feed-forward network of expansion factor~$4$. A learned query token
aggregates the final node representations via cross-attention, producing the
latent vector~$z \in \mathbb{R}^{384}$.

\subsection{Predictor}

Given the current latent $z$ and a rule identifier~$a$, the predictor
outputs a forecast $\hat{z}' = f_\theta(z, a)$. We adopt a $6$-layer
causal Transformer with Adaptive LayerNorm-Zero
(AdaLN-Zero)~\cite{peebles2023dit} conditioning: the rule embedding
produces shift, scale, and gate vectors that modulate the attention and
feed-forward sub-layers. The modulation parameters are zero-initialized so
that each block begins as an identity function, stabilizing early training.

\subsection{Collapse Prevention}

Both encoder paths (input expression and result expression) receive
gradients---no stop-gradient or exponential moving average is used.
Collapse is prevented by SIGReg~\cite{balestriero2025lejepa}, which
projects embeddings onto $1{,}024$ random unit directions and penalizes
deviation from an isotropic Gaussian via the Epps--Pulley characteristic
function test with trapezoidal integration over $[0, 3]$ using $17$
quadrature knots. We set the regularization weight $\lambda = 0.09$.

\subsection{Value Head}

A $3$-layer MLP with Softplus output predicts $\text{cnf\_distance}$ from a
latent vector. It is trained on \emph{every} batch using the true
$\text{cnf\_distance}$ of result expressions ($280{,}286$ supervision
signals per epoch). Gradients from the value loss do not flow into the
encoder; the value head receives detached latent vectors. This prevents the
value objective from reshaping the representation learned for dynamics
prediction~\cite{destrade2026valueguided}.

\subsection{Training Objective}

The total loss is
\begin{equation}
\mathcal{L} = \underbrace{\lVert f_\theta(z_s, a) - z_{s'} \rVert_2^2}_{
\text{prediction}} + \lambda \cdot \underbrace{
\mathcal{L}_{\text{SIGReg}}}_{\text{collapse prevention}} +
\underbrace{\lVert v_\phi(z_{s'}) - R(s') \rVert_2^2}_{\text{value}},
\end{equation}
where $z_s$ and $z_{s'}$ are the encoder outputs for the input and result
expressions, $f_\theta$ is the predictor, $v_\phi$ is the value head, and
$R(s') = \text{cnf\_distance}(s')$. Training uses AdamW
($\text{lr} = 10^{-3}$, weight decay $0.01$) with cosine annealing,
batch size~$48$, and gradient clipping at norm~$1.0$.

\subsection{Planning}

At test time, the model selects actions greedily:
(1)~encode the current expression to latent~$z$;
(2)~for each valid action~$a_i$, predict $\hat{z}'_i = f_\theta(z, a_i)$
and score $v_\phi(\hat{z}'_i)$;
(3)~apply the action with lowest predicted $\text{cnf\_distance}$;
(4)~the symbolic engine executes the rewrite.
This repeats for at most $25$ steps. The model decides \emph{which} rule
to apply; it never produces a rewritten expression.

\section{Experiments}

\subsection{Data}

Training data is generated synthetically: random expression trees of depth
$2$--$6$ are constructed, and all valid (expression, rule, result) triples
are enumerated. We generate $50{,}000$ unique expressions for training
($280{,}286$ samples), $5{,}000$ for validation ($27{,}095$), and
$10{,}000$ for test ($53{,}766$). Splits use different seeds; no expression
appears in multiple splits.

\subsection{Evaluation}

We evaluate solve rate on $300$ randomly generated non-CNF expressions
(fixed seed). A solve is reaching $\text{cnf\_distance} = 0$ within $25$
steps. All results are mean~$\pm$~std over three training seeds ($42$,
$137$, $256$).

\paragraph{Baselines.}
(i)~\emph{Greedy oracle}: at each step, computes the true
$\text{cnf\_distance}(s') + 0.01 \cdot \text{node\_count}(s')$ for every
candidate result and picks the minimum. This baseline sees ground-truth
outcomes that our model does not.
(ii)~\emph{Random}: selects a uniformly random valid action.

\Cref{tab:main} shows that the learned value function outperforms the
greedy oracle by $1.7$ percentage points despite operating under strictly
less information. The oracle is vulnerable to local optima: the
distribution rule $A \vee (B \wedge C) \mapsto (A \vee B) \wedge (A \vee
C)$ reduces $\text{cnf\_distance}$ by $1$ but may double expression size,
exhausting the step budget. The learned value function avoids these traps.

All methods solve $100\%$ of depth-$2$ through depth-$5$ expressions. At
depth~$6$ ($290$ of $300$ test expressions), solve rates are $30.9 \pm
0.6\%$ (ours), ${\sim}28\%$ (oracle), and ${\sim}15\%$ (random).

\subsection{Representation Analysis}

\paragraph{Semantic clustering.}
We define the Semantic Clustering Score (SCS) as the ratio of mean
inter-class to mean intra-class cosine distance, where classes are
truth-table equivalence groups. Using a $128$-dimensional encoder trained
with SIGReg (three seeds), we measure $\text{SCS} = 5.76 \pm 0.12$:
logically equivalent expressions are $5.8\times$ closer than
non-equivalent ones. No supervision on truth tables is provided during
training; the structure emerges from predicting rewrite outcomes.

\paragraph{Collapse ablation.}
Removing SIGReg causes the effective rank of the encoder output covariance
to drop from $91\%$ to $16\%$ of the embedding dimension
($0.71 \pm 0.03$ vs.\ $0.16 \pm 0.08$). Semantic clustering vanishes
($\text{SCS} = -0.26 \pm 0.63$). This confirms that latent prediction loss
alone admits trivial constant-encoder solutions, as formalized by
Proposition~1 of~\citet{xing2025critiques}.

\section{Discussion}

\paragraph{What the model learns.}
The model discovers rewrite dynamics without rule definitions and, as a
byproduct, learns to represent logical equivalence---an unsupervised
structural property of the domain. The value function learns an action
scoring criterion that avoids local optima the greedy heuristic falls into.

\paragraph{Limitations.}
The domain is small: four variables and depth at most six. Classical
algorithms (e.g., Tseitin transformation) solve CNF conversion perfectly.
An LLM given the rule definitions also achieves $100\%$ via chain-of-thought
reasoning. The contribution here is not solving CNF conversion---it is
demonstrating that latent world models can learn discrete symbolic dynamics
and produce semantically meaningful representations. Whether this scales to
domains where classical methods are insufficient remains open.

At $384$ dimensions, the representation rank stabilizes at $0.08$ despite
SIGReg ($\lambda = 0.09$), suggesting the regularization weight should
scale with embedding dimension. Solve rate variance across seeds is low
($\pm 0.2\%$), but evaluation uses a fixed set of $300$ test expressions.

\paragraph{Broader context.}
All existing JEPA world models operate on pixels and continuous control. By
applying the architecture to discrete trees with deterministic combinatorial
transitions, we extend the empirical scope of joint-embedding predictive
world models. The finding that semantic equivalence emerges unsupervised may
be of independent interest for representation learning on structured
symbolic data.
